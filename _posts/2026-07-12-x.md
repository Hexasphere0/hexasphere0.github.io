Today, I started by finally fixing single player. When I implemented multiplayer, I accidentally made it so you can't just load into a scene without going into the lobby. This obviously makes testing levels impossible. I fixed this by making every scene have a network manager that starts itself. This allows for single player to work. Additionally, when these network managers load, if there is another one present, they delete themselves, which means the scenes work fine in multiplayer without having to do any manual changes.
