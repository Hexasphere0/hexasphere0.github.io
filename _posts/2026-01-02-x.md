My goal for the game is to be kind of like a dungeon crawler, but where your run resets every time. There won't be progress stored between runs, because that is out of the scope for right now. I hope that as I improve the upgrade system, it can diverge further into its own unique game. In order to finish the demo of the game, I need to complete a few things:
- [ ] Add 3 main bosses, which will spawn every 3 floors.
- [ ] Have around 15 upgradable abilities.
- [ ] Have different floors for you to clear.

So far, I have implemented 0 bosses. This will probably be the last thing I work on for this project, because I think it will be easier to make them after I finish the rest of the systems. I plan for the bosses to have large AOE attacks that the player will need to dodge, while trying to damage the boss at the same time.

One system I need to implement is floors. Each floor should have a simple path forward to the next floor, as well as enemies to clear. The enemies should be placed around the level somewhat randomly, but not fully randomly as they are right now. the enemies will also not be endlessly spawning. I think the enemies being endlessly spawning will complicate boss fights, as well as be really punishing to the player, not allowing them to progress at their own pace. I also find that it becomes really monotone. This can be fixed, but it would require a different direction than my vision for the game right now. Some things I will need to implement:
- [ ] A simple levels system that allows the user to move between different scenes
- [ ] A modification of the enemy spawner to pre-spawn enemies in the scene in different areas of interest, instead of endlessly spawning them.

Out of the planned abilities, I have implemented the following so far:
- Shield: Spawns a shield around the player, that can take up to 3 hits before dissipating.
- Heal: Heals the player.
- Basic Shot: The basic ability unlocked from the start of a run, that allows the player to shoot a projectile at enemies.
- Burst: Spawns an explosion centered at the player.
- Explosion: Spawns an explosion at the mouse pointer.
- Poison Cloud: Creates a poison cloud that deals damage to enemies every second.
- Frost Nova: Creates an explosion that also slows enemies.
- Blink: Teleports the player to the mouse pointer.
- Dash: Moves the player forwards in the direction they are currently traveling.

I would like to implement:

- [x] A meteor attack, that creates a giant piercing projectile.

Another system that will take a lot of time to implement is the upgrade system. I want the upgrade system to work in modules. Each upgrade can be added onto an ability in order to modify its behavior. Some upgrades will be simple, such as changing the damage or cooldown of an ability. Others will be more complicated, such as slowing damaged enemies. I plan to remove the frost nova ability as it will be redundant with this change. Each ability will define the upgrade modules it can support. I also need to add tooltips, so players can see what the abilities do and what upgrades they have on them. This will need to the following to be implemented:
- [ ] Reading ability information off of a data file.
- [ ] Moving abilities to their own game object.
- [ ] Creating a base upgrade class in the code.
- [ ] Create an upgrade for each basic stat, like damage.
- [ ] Add a slowing upgrade.
- [ ] Tooltips

After all of this, the last major hurdle will be to revamp the visuals of the game. This will require a background, as well as particle effects for all the abilities. I also will need to add shadows to make the game look less flat.
