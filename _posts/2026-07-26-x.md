Today, I worked on a new progress bar mode for the new level. 

![[Pasted image 20260728160418.png]]

The goal of this level is to collect every checkpoint in any order you want. Therefore, you have to work to find the best route through the level, which is the main challenge. Previously, you only collected checkpoints in chronological order, but now there is a mode you can enable to make it so the user can collect checkpoints in any order, and the progress bar counts the number of checkpoints collected. I also restored the previous and next checkpoint button functionality from the previous level manager. Finally, I made the progress bar only update when an event is triggered by the checkpoint manager. This helps remove extra computation, especially related to the progress bar.

I also changed the colors slightly to be more darker. I think this helps blend them in with the new background.
