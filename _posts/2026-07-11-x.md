Currently, the card search feature is completed. The things that need to be completed are:

- Next, we will need to finish implementing the deck builder. This should allow the user to search and drag cards into a deck, and export it as a deck image or ready to print proxies.
- Finally, we will need to redo the UI. I am going to do this manually.

After all of this, I think the website will be ready to publish and useful to the community.
