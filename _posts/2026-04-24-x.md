Today, I worked on a couple of minor improvements in my game.

First, I added in the new tile set to see how it looked in game. This required creating a couple shaders with the shader graph. I needed a shader for gradients, and a shader for emissive textures. Creating a gradient for emissive textures was pretty easy, but I wasn't able to figure out how to do this for gradients yet. I got colors working to some extent, but it looks unnatural, and doesn't support alpha. I need alpha, because the goal of the gradient is to create a fog like effect on the bottom of the level.

In this process, I learned a little bit more about how the shader graph works. The UV node can be used to change the way a shader behaves based on the area of the object it is targeting, which is very useful for a gradient.
