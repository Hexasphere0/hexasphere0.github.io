Today in the platformer game, I created a new random world level. I created a script that distributes blocks randomly, and continues creating new chunks as the player progresses upwards. The goal is to climb as far as possible. As you get higher, the distance between the random blocks increases, making it harder to progress.

I also created a gradient shader, that will allow the blocks to look more dynamic. I tried doing this a while ago, but it didn't work and I couldn't figure out what I was doing wrong. This time, I followed a tutorial and it worked. I also made the shader take a Boolean value to select which color map it used, which allows me to swap the colors dynamically for the player without causing lag. 

Next, I added a trail to the player using the inbuilt trail feature. I also created a variant of the gradient shader called gradient tilemap shader, which allows it to calculate UV's in world space. This makes it look way better in the world, as all the gradients aren't synchronized.
