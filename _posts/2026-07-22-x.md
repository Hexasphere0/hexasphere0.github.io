Today, I worked on refactoring a lot of code in my game. A big problem that I made a band aid fix for was the level management system (the checkpoints and progress bar), which completely broke when I ported to multiplayer. I finally fixed it. To start, I moved a bunch of the level manager logic to a new script called checkpoint manager, which exists on each player object. When the player runs into a checkpoint, the manager enables that checkpoint in the list of objects. Previously, I wasn't able to get this working because I ran into issues where the list of checkpoints wasn't properly initializing when changing scenes. I originally added an event that gets called when changing scenes to call the initialize function, but I kept getting the checkpoints from the previous scene and not the one I was loading into. I figured the issue was because I was using Find Objects before the scene fully finished loading, but I couldn't figure out a working fix for a while. I finally figured out that I could just call initialize when the player ran into a checkpoint instead of when the scene loads. The checkpoint manager now keeps track of whether it is initialized or not, and when you collect a checkpoint, if it isn't initialized, it will initialize the array of checkpoints. This worked, but then I ran into an issue where only one player could collect a checkpoint. This was because of leftover code from the previous checkpoint logic, which was pretty easy to fix.
